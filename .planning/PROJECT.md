# AI Chat 玩具 - 项目定义

## 这是什么

AI Chat 玩具是一个现代化的AI对话平台，深度集成MiniMax Token Plan API，提供企业级的对话、检索增强生成(RAG)、Agent协作和人机协作(HITL)能力。

## 核心价值

**一句话**: 面向开发者的下一代AI编程助手平台

**核心能力**:
- 基于MiniMax M2.7旗舰模型的智能对话
- 意图驱动的工具调用和Agent协作
- RAG知识库问答，减少幻觉
- HITL人机协作，关键操作需人工确认
- 多模态交互（图片理解、语音录制）
- 思维链可视化，理解AI推理过程

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 19, Next.js 15, Zustand 5, Tailwind |
| 后端 | Express 4.18, Node.js |
| 模型 | MiniMax Token Plan API (M2.7/VL-01/Text-01) |
| 向量 | Qdrant, Ollama (可选) |
| 协议 | MCP, A2A, SSE |

## 架构

六层DDD架构：
- `routes/` - HTTP接口层
- `services/` - 业务逻辑层
- `application/` - 应用编排层
- `domain/` - 核心业务域
- `infra/` - 基础设施
- `common/` - 通用基础
