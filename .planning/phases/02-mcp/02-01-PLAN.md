<task type="auto">
  <name>Task 2: 实现工具执行和结果返回机制</name>
  <files>
    - backend/src/services/mcp.js
  </files>
  <action>
    读取现有 `services/mcp.js`。

    增强 `MCPToolExecutor` 类，实现真实工具执行逻辑：
    1. `executeTool(toolName, args, context)` - 执行工具，返回标准化结果
    2. `executeWithTimeout(toolName, args, timeoutMs)` - 超时保护（默认30秒）
    3. `formatToolResult(toolName, result)` - 格式化结果为 MCP 协议格式

    MCP 协议结果格式：
    ```javascript
    {
      success: true,
      tool: "tool_name",
      result: { ... },  // 工具执行结果
      executionTime: 123,
      timestamp: Date.now()
    }
    ```

    错误格式：
    ```javascript
    {
      success: false,
      tool: "tool_name",
      error: { code: "TIMEOUT", message: "..." },
      timestamp: Date.now()
    }
    ```

    确保每个工具执行后记录日志（使用 AgentLogger）。
  </action>
  <verify>
    <automated>grep -c "executeWithTimeout" backend/src/services/mcp.js && grep -c "formatToolResult" backend/src/services/mcp.js</automated>
  </verify>
  <done>
    POST /api/mcp/call 执行工具返回标准化 MCP 格式结果
  </done>
</task>
