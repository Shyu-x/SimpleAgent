    读取现有 `services/MultiAgentCoordinator.js`（如果不存在则创建）。

    增强协调器实现三种协调模式：

    1. **team_leader 模式**:
       - 主Agent负责任务分解和分配
       - 从Agent执行被分配的任务
       - 主Agent汇总结果

    2. **collaborative 模式**:
       - 所有Agent对等协作
       - 共享任务队列
       - 结果合并

    3. **autonomous 模式**:
       - Agent独立执行
       - 最小协调，仅在依赖点同步
       - 并行执行无依赖任务

    协调模式数据结构：
    ```javascript
    {
      mode: "team_leader" | "collaborative" | "autonomous",
      leaderAgent: "agent-id",  // 仅 team_leader
      agents: ["agent-1", "agent-2"],
      taskQueue: [...],
      completedTasks: []
    }
    ```

    实现任务依赖图验证：循环依赖检测、缺失依赖检测。
  </action>
  <verify>
    <automated>grep -c "team_leader\|collaborative\|autonomous" backend/src/services/MultiAgentCoordinator.js</automated>

  </done>

<task type="auto">
  <name>Task 2: 实现生命周期钩子系统</name>
  <files>
    - backend/src/services/MultiAgentCoordinator.js
  </files>
  <action>
    读取 Task 1 创建或修改的文件。

    实现生命周期钩子系统，支持以下事件：

    | 钩子 | 触发时机 | 数据 |
    |------|----------|------|
    | `task:created` | 任务创建 | { taskId, taskDef } |
    | `task:started` | 任务开始执行 | { taskId, agentId } |
    | `task:completed` | 任务完成 | { taskId, result } |
    | `task:failed` | 任务失败 | { taskId, error } |
    | `task:skipped` | 任务跳过（依赖失败）| { taskId, reason } |
    | `collaboration:started` | 协作开始 | { collaborationId, mode } |
    | `collaboration:completed` | 协作完成 | { collaborationId, summary } |
    | `collaboration:failed` | 协作失败 | { collaborationId, error } |

    钩子注册接口：
    ```javascript
    coordinator.onHook('task:completed', (data) => {
      console.log('Task completed:', data.taskId);
    });
    coordinator.offHook('task:completed', handler);
    ```

    SSE模式下自动推送钩子事件到客户端。
  </action>
  <verify>
    <automated>grep -c "onHook\|offHook\|emitHook" backend/src/services/MultiAgentCoordinator.js</automated>
  </verify>
  <done>
    生命周期钩子可注册/注销，事件正确触发
  </done>
