<interfaces>
<!-- Knowledge API Endpoints -->
Backend Knowledge API:
- GET /api/admin/knowledge/docs?search=&status=&page=&pageSize= -> { success, data: { documents, total, page, pageSize } }
- GET /api/admin/knowledge/stats -> { success, data: { totalDocuments, totalChunks, indexSize, status, knowledgeBases } }
- GET /api/admin/knowledge/search?q=&topK= -> { success, data: { results, count } }
- POST /api/admin/knowledge/docs -> upload document (multipart/form-data)
- DELETE /api/admin/knowledge/docs/:id?kbId= -> delete document
- POST /api/admin/knowledge/reindex -> rebuild index

<!-- Tool API Endpoints -->
Backend Tool API:
- GET /api/admin/tools -> { success, data: { tools, total, categories } }
- GET /api/admin/tools/categories -> { success, data: { categories } }
- GET /api/admin/tools/:name -> { success, data: tool detail }
- POST /api/admin/tools/register -> { success, data: { name, category } }
- PATCH /api/admin/tools/:name -> { success, data: { name, enabled } }
- PUT /api/admin/tools/:name -> update tool config
- DELETE /api/admin/tools/:name -> delete tool
- POST /api/admin/tools/:name/test -> test tool execution
- GET /api/admin/tools/categories/list -> { success, data: { categories, byCategory } }
</interfaces>
