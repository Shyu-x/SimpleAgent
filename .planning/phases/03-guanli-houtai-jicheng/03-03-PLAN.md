<interfaces>
<!-- Model API Endpoints -->
Backend Model API:
- GET /api/admin/models -> { success, data: { models, total, defaultModel } }
- GET /api/admin/models/stats -> { success, data: { totalRequests, totalTokens, avgLatency, successRate, topModels, circuitBreakers } }
- GET /api/admin/models/:name -> model detail with circuit breaker
- PATCH /api/admin/models/:name -> update enabled status
- PUT /api/admin/models/:name -> update config (包含 resetCircuit)
- POST /api/admin/models/:name/circuit-breaker -> reset circuit breaker

<!-- Trace API Endpoints -->
Backend Trace API:
- GET /api/admin/traces -> { success, data: { traces, total, limit, offset, hasMore } }
- GET /api/admin/traces/stats -> { success, data: { overview, recent, performance, distribution } }
- GET /api/admin/traces/:traceId -> trace detail with spans
- GET /api/admin/traces/:traceId/spans -> spans list

<!-- Prompt API Endpoints -->
Backend Prompt API:
- GET /api/admin/prompts -> { success, data: { templates, total } }
- GET /api/admin/prompts/:id -> template detail
- POST /api/admin/prompts -> create template
- PUT /api/admin/prompts/:id -> update template
- DELETE /api/admin/prompts/:id -> delete template
- POST /api/admin/prompts/:id/test -> test template render
- GET /api/admin/prompts/:id/versions -> { success, data: { versions, currentVersion } }
- POST /api/admin/prompts/:id/rollback -> rollback to version
</interfaces>
