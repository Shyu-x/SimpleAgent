/**
 * Git 分支命名规范说明
 * 
 * 采用 Trunk-Based Development + 模块化特性分支
 * 
 * 分支类型：
 * 1. main - 主分支，生产环境代码
 * 2. develop - 开发主分支（可选，用于集成）
 * 3. feature/module-{模块名}/{功能简述} - 特性分支
 * 4. hotfix/{问题描述} - 热修复分支
 * 5. release/{版本号} - 发布分支
 * 
 * 模块标识：
 * - auth: 认证模块
 * - user: 用户模块
 * - order: 订单模块
 * - payment: 支付模块
 * - notification: 通知模块
 * - admin: 管理后台
 * - infra: 基础设施
 * - docs: 文档更新
 * 
 * 示例：
 * feature/auth/jwt-refresh
 * feature/order/coupon-system
 * feature/user/avatar-upload
 * hotfix/payment-refund-loop
 * release/v2.1.0
 */

## 分支策略图示

main (生产环境)
    ↑
    │ hotfix/v1.2.1
    │     ↓
release/v1.2.0 ──────┐
    ↑               │
    │               ↓
    │         feature/order/coupon-system
    │               │
feature/auth/social-login ──────┤
    ↑                       │
    └───────────────────────┘
    
develop (集成分支，可选)
    ↑
    └── feature/* (特性分支)

## 快速参考

| 操作 | 命令 |
|------|------|
| 创建特性分支 | git checkout -b feature/auth/jwt-refresh |
| 切换模块分支 | git checkout feature/auth |
| 创建热修复 | git checkout -b hotfix/payment-bug main |
| 创建发布分支 | git checkout -b release/v2.1.0 develop |
