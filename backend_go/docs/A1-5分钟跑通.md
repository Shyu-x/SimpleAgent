# Go后端 - 5分钟跑通

## 这是什么？
Gin 框架构建的高性能后端服务
- 端口：8080
- 特性：协程并发、极简路由、高性能

## 环境准备
- Go 1.21+
- Git

## 第一步：进入目录（1分钟）
```bash
cd backend_go
```

## 第二步：下载依赖（1分钟）
```bash
go mod tidy
```

## 第三步：启动服务（1分钟）
```bash
go run cmd/server/main.go
```

## 第四步：验证（1分钟）
```bash
curl http://localhost:8080/health
```
应该返回 `{"status":"ok"}`

## 测试 API
```bash
curl http://localhost:8080/api/chat -X POST \
  -H "Content-Type: application/json" \
  -d '{"message":"你好"}'
```

## 发生了什么？
```
go run → 编译并运行 → main.go
                              ↓
                        Gin 注册路由
                              ↓
                        HTTP 服务器
                              ↓
                        监听 8080 端口
```

## Go 核心特性（对比 Node.js）

| 特性 | Go | Node.js |
|------|-----|---------|
| 并发模型 | 协程 (goroutine) | 单线程 + 事件循环 |
| 内存管理 | 自动回收（逃逸分析） | V8 自动回收 |
| 类型系统 | 静态类型 + 接口隐式实现 | 动态类型 |
| 错误处理 | 返回 error 值 | try/catch |

## 常见问题

Q: 端口被占用？
A: 修改 `cmd/server/main.go` 中的端口，或设置 `PORT` 环境变量

Q: 编译报错？
A: 确保 Go 版本 >= 1.21，运行 `go version` 检查

Q: 如何热重载？
A: 使用 `air` 工具：`go install github.com/air-verse/air@latest`
