### 发现的问题

#### 🔴 关键问题 (需立即修复)

1. **欢迎引导遮罩阻挡**
   - 位置: 首次加载时显示
   - 影响: 阻挡所有交互按钮
   - 解决方案:
     ```javascript
     // 在测试中添加关闭引导逻辑
     await page.click('button:has-text("跳过")');
     await page.waitForTimeout(500);
     ```

2. **左下角调试信息**
   - 位置: 所有界面左下角
   - 内容: "1 Issue" 红色标记
   - 影响: 影响用户体验，应在生产环境移除
   - 解决方案: 检查 Next.js 错误提示，修复代码问题

#### 🟡 次要问题 (建议优化)

1. **部分按钮未找到**
   - 记忆按钮、设置按钮等选择器可能不准确
   - 建议: 统一添加 aria-label 属性

2. **布局切换器未找到**
   - 可能需要检查组件是否正确挂载
   - 建议: 检查 MultiWindowChat 组件
