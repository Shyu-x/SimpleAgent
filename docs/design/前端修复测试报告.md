### P0 - 立即修复

**1. 全局 ErrorBoundary (page.tsx)**

- 确保任何组件崩溃都能显示友好降级 UI，不会白屏

### P1 - 本周修复

**2. 统一断点定义 (page.tsx + globals.css)**
- `page.tsx` 第103行: `useMediaQuery('(max-width: 640px)')` - 从 639px 改为 640px
- `globals.css`: 全部 `max-width: 639px` 改为 `max-width: 640px`
- 与 Tailwind 默认断点保持一致

**3. 修复侧边栏高度计算 (page.tsx)**
- 在背景装饰层添加 `overflow-hidden`
- 确保侧边栏滚动正确处理

**4. 修复 ChatArea 容器 min-h-0 (page.tsx)**
- 第408行: `<div className="flex flex-1 min-h-0 overflow-hidden px-3 pb-3 pt-2">`
- 第409行: `<div className="h-full min-h-0 overflow-hidden rounded-3xl ...">`
- 确保 flex 子元素能正确收缩

**5. Header 按钮响应式处理 (page.tsx)**
- 将 `hidden xl:inline` 改为 `hidden lg:inline`
- 在 lg 断点(1024px)就开始显示文字，更早响应

### P2 - 计划修复

**6. DropZone 布局逻辑重构 (MultiWindowChat.tsx)**
- 添加 `getWindowClassName()` 辅助函数，逻辑清晰分离
- 单窗口模式下，使用 `shouldHide` 提前返回 null
- 使用 `getContainerStyles()` 统一容器样式

**7. 主题切换闪烁优化 (layout.tsx)**
- 在 `<head>` 中添加内联脚本
- 在 React 水合前读取 localStorage 并设置主题类
- 避免客户端 hydration 后闪烁

**8. ChatArea 容器高度优化 (page.tsx)**
- 确认 ChatArea.tsx 已有 `flex-1 overflow-y-auto` 滚动容器
- 无需额外修改

**9. 动画退出时长一致性**
- 确认 page.tsx 中所有 exit 动画统一为 `duration: 0.25` + `ease: [0.16, 1, 0.3, 1]`

**10. 移动端安全区域验证 (MobileLayout.tsx)**
- 确认使用 `safe-area-top` 和 `safe-area-bottom` CSS 类
- 通过 `MobileExperienceProvider` 运行时获取 safe-area-inset
