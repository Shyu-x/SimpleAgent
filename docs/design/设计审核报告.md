## 六、设计工具安装建议

### 6.1 推荐工具链

| 工具 | 用途 | 链接 |
|------|------|------|
| **Style Dictionary** | Design Token 转换 | `npx style-dictionary` |
| **Storybook** | 组件文档化 | `@storybook/react` |
| **Storybook Design Tokens** | Token 可视化 | `@storybook/addon-design-tokens` |

### 6.2 安装命令

```bash
# 安装 Style Dictionary (推荐用于 OpenDesign)
cd frontend
npm install --save-dev style-dictionary

# 初始化配置
npx style-dictionary init

# 安装 Storybook (可选，用于组件文档)
npm install --save-dev storybook @storybook/react @storybook/react-vite
```

### 6.3 Design Token 导出配置

```javascript
// style-dictionary.config.js
module.exports = {
  source: ['src/**/*.{css,scss}'],
  platforms: {
    web: {
      transformGroup: 'css',
      prefix: 'sd',
      buildPath: 'src/tokens/',
      files: [{
        destination: 'tokens.css',
        format: 'css/variables',
        options: {
          outputReferences: true
        }
      }]
    }
  }
};
```
