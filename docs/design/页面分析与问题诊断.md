## 三、发现的潜在问题

### 3.1 显示区域问题 (Display Issues)

#### 问题 1: 侧边栏高度计算不一致
```
位置: page.tsx, line 284
代码:
  <motion.aside
    className="my-3 ml-3 ... h-screen ..."
  >
```

**问题**: 侧边栏使用 `h-screen`，但外层没有设置 `overflow:hidden`，可能导致滚动时出现双滚动条。

**建议修复**:
```css
/* globals.css 添加 */
.sidebar-container {
  height: calc(100vh - 1.5rem); /* my-3 = 0.75rem * 2 */
  overflow: hidden;
}
```

#### 问题 2: ChatArea 容器高度计算
```
位置: page.tsx, line 421-422
代码:
  <div className="flex-1 overflow-hidden px-3 pb-3 pt-2">
    <div className="h-full overflow-hidden rounded-3xl ...">
```

**问题**: 内部容器 `h-full` 依赖父元素 `flex-1`，但没有明确的 `overflow` 控制，可能导致嵌套溢出。

**建议修复**:
```tsx
<div className="flex-1 overflow-hidden px-3 pb-3 pt-2">
  <div className="h-full min-h-0 overflow-hidden rounded-3xl ...">
    {/* min-h-0 允许 flex 子元素收缩 */}
  </div>
</div>
```

#### 问题 3: 多窗口 DropZone 布局问题
```
位置: MultiWindowChat.tsx, line 91-95
代码:
  className={`
    relative flex flex-col overflow-hidden rounded-3xl
    border border-[hsl(var(--border-subtle))]
    bg-[hsl(var(--bg-surface))]/92 shadow-lg backdrop-blur-xl
    ${layout === 'single' ? (index === windowIds.length - 1 ? 'flex-1 w-full h-full' : 'hidden') : ''}
  `}
```

**问题**:
1. `layout === 'single'` 时使用条件三元组，逻辑复杂
2. `index === windowIds.length - 1` 的判断可能不正确（当 windowIds 为空时）

**建议修复**:
```tsx
const isLastAndOnly = layout === 'single' && windowIds.length === 1 && index === 0;

className={`
  relative flex flex-col overflow-hidden rounded-3xl
  ${layout === 'single' && !isLastAndOnly ? 'hidden' : 'flex-1 w-full h-full'}
  ${layout !== 'single' ? `border border-[hsl(var(--border-subtle))]` : ''}
`}
```

#### 问题 4: 移动端安全区域适配
```
位置: MobileLayout.tsx, line 71
代码:
  <div className="safe-area-top flex h-[100dvh] w-full flex-col overflow-hidden ...">
```

**问题**: `100dvh` 在 iOS Safari 底部栏展开时可能显示不完整（动态视图高度）。

**建议**: 已有 `safe-area-top`，但缺少底部安全区域验证。

#### 问题 5: Header 按钮溢出

```
位置: ConversationList.tsx
问题: 长标题可能导致布局溢出
```

```tsx
<p className="truncate text-sm font-semibold">

</p>
```

### 3.3 渲染问题 (Rendering Issues)

#### 问题 7: 主题切换闪烁 (Flash)
```
位置: page.tsx, line 182-198
代码:
  useEffect(() => {
    root.dataset.theme = settings.theme;
    root.classList.add/remove('dark');
  }, [settings.theme, desktopPalette]);
```

**问题**: 客户端 hydration 后才应用主题，可能出现闪烁。

**建议**: 使用 `@nuxtjs/color-mode` 或服务端注入 theme class。

#### 问题 8: 动态导入的 SSR 边界
```
位置: page.tsx, line 28-31
代码:
  const ToolMarketplace = dynamic(
    () => import('@/components/agent/ToolMarketplace'),
    { ssr: false }
  );
```

**问题**: `ssr: false` 可能导致首次加载时布局跳动。

**建议**: 添加 loading skeleton:
```tsx
const ToolMarketplace = dynamic(
  () => import('@/components/agent/ToolMarketplace'),
  {
    ssr: false,
    loading: () => <div className="animate-pulse h-full w-full bg-muted rounded-lg" />
  }
);
```

### 3.4 动画与过渡问题

#### 问题 9: LayoutGroup 嵌套冲突
```
位置: page.tsx, line 274
代码:
  <LayoutGroup>
    <AnimatePresence>
      {sidebarOpen && <motion.aside layout ...>}
    </AnimatePresence>
    <motion.main layout ...>
      {/* 内部 ChatArea 也使用 AnimatePresence */}
    </motion.main>
  </LayoutGroup>
```

**问题**: 多个 `LayoutGroup` 可能导致布局动画冲突。

**建议**: 确保每个 `layout` 元素有唯一的 `layoutId`。

#### 问题 10: Exit 动画时长不一致
```
位置: page.tsx, line 422-460
代码:
  exit={{ opacity: 0, scale: 0.98 }}
  transition={{ duration: 0.25, ease: [0.16, 1, 0.3, 1] }}

Sidebar exit:
  exit={{ x: -24, opacity: 0 }}
  transition={{ type: 'spring', damping: 28, stiffness: 260 }}
```

**问题**: 不同组件使用不同的退出时长，影响体验一致性。

### 3.5 状态管理问题

#### 问题 11: 重复的 conversationId 查找
```
位置: ChatArea.tsx, line 71-74
代码:
  const activeConversation = useMemo(
    () => conversations.find((c) => c.id === activeConversationId),
    [conversations, activeConversationId]
  );
```

**问题**: 如果 conversationId 不存在，返回 undefined，但组件未处理这种情况。

**建议**:
```tsx
const activeConversation = useMemo(
  () => conversations.find((c) => c.id === activeConversationId),
  [conversations, activeConversationId]
);

if (!activeConversation) {
  return <div className="flex items-center justify-center h-full">对话不存在</div>;
}
```

#### 问题 12: 移动端 View 状态同步
```
位置: MobileLayout.tsx, line 58
代码:
  const [currentView, setCurrentView] = useState<MobileView>('chat');
```

**问题**: `appMode` 和 `currentView` 是两个独立状态，可能导致不一致。

**建议**: 使用单一的视图状态机，或确保状态变更时互相同步。

### 3.6 响应式问题

#### 问题 13: 断点不一致
```
globals.css:
  @media (max-width: 639px) { /* 移动端 */ }
  @media (min-width: 640px) and (max-width: 1023px) { /* 平板 */ }

page.tsx:
  const isMobile = useMediaQuery('(max-width: 639px)');
```

**问题**: Tailwind 默认断点 (sm: 640px) 与代码中使用的 639px 不一致。

**建议**: 统一使用 Tailwind 断点:
```tsx
// 替换
const isMobile = useMediaQuery('(max-width: 639px)');
// 为
const isMobile = useMediaQuery('(max-width: 640px)');  // 使用 Tailwind sm
```
