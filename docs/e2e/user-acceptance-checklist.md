## 一、核心用户旅程 (User Journey)

### 旅程 1: 首次使用 (New User Onboarding)

```
[用户打开页面]
     ↓
[首次访问?]
     │
     ├─ 是 → WelcomeGuide 引导 (5步)
     │         ↓
     │    Step 1: 欢迎页 (呼吸动画 + 特性标签)
     │         ↓
     │    Step 2: 功能介绍 (多对话/实时流式/配置/隐私)
     │         ↓
     │    Step 3: 示例演示 (打字机效果)
     │         ↓
     │    Step 4: API 配置 (模型选择 + Key 输入 + 端点配置)
     │         ↓
     │    Step 5: 完成确认 (快捷键提示)
     │         ↓
     │    [完成] → localStorage.onboarding-completed = true
     │
     └─ 否 → 检查会话恢复
              ↓
         [有历史会话?] → 恢复最近会话
              │
              └─ 无 → 创建新会话 → 显示欢迎消息
```

**验收点:**
- [ ] WelcomeGuide 居中显示 (flex items-center justify-center)
- [ ] 5步引导完整展示，每步可前进/后退
- [ ] API Key 格式验证正确
- [ ] 预设模型选择正确 (MiniMax M2.7 默认)
- [ ] 完成引导后不再显示欢迎弹窗

---

### 旅程 2: 发送消息并接收流式响应

```
[用户输入消息 "你好"]
     ↓
[点击发送 / Ctrl+Enter]
     ↓
[检测图片生成意图?]
     │
     ├─ 是 → 调用 /api/minimax/image → 显示图片消息
     │
     └─ 否 → 构建 messages 数组
              ↓
         [联网搜索启用?] → 注入搜索结果到用户消息
              ↓
         [深度思考启用?] → 启用 thinking 区块显示
              ↓
         sendSSEChatMessage() → 后端流式响应
              ↓
         ┌────────────────────────────────────┐
         │         SSE 数据处理                 │
         │                                     │
         │  thinking_delta → 思维链区域更新    │
         │  choices delta → 消息内容追加       │
         │  thinking_complete → 思维链完成     │
         │  [DONE] → 消息完成标记              │
         └────────────────────────────────────┘
              ↓
         [打字机效果显示]
              ↓
         [消息 isComplete = true]
```

**验收点:**
- [ ] 输入框支持多行输入 (Shift+Enter)
- [ ] IME 输入保护正常 (输入法期间不触发发送)
- [ ] 发送时禁用输入框，显示 loading 状态
- [ ] **思维链和回复同时显示** (不丢数据)
- [ ] 打字机效果流畅 (可配置速度 10-100ms)
- [ ] 发送失败显示错误 Toast
- [ ] 自动滚动到最新消息 (除非用户主动上滑)

### 旅程 3: 对话管理

```

[新建会话] → 创建空白会话，切换到新会话

[删除会话] → 确认对话框 → 删除

```

**验收点:**
- [ ] 会话列表显示所有历史会话
- [ ] 当前会话高亮显示
- [ ] 新建会话自动切换
- [ ] 删除有确认提示
- [ ] 切换会话保持独立状态

## 六、验收执行计划

### Phase 1: 核心路径验证 (P0)

```
1. 启动应用 (pm2 restart all)
2. 访问 http://localhost:3001
3. 验证 WelcomeGuide 居中
4. 完成引导配置 (输入 API Key)
5. 发送 "你好" 消息
6. 验证:
   - 思维链显示
   - 回复内容显示
   - 两者同时存在
```

### Phase 2: 完整用户旅程 (P1)

```
1. 新建会话 → 发送复杂问题 → 验证流式响应
2. 切换会话 → 验证历史加载
3. 测试功能开关 → 验证切换效果
4. 测试侧边面板 → 验证打开关闭
```

### Phase 3: 边界与性能 (P2)

```
1. 空消息发送 → 验证禁用
2. 无效 API Key → 验证提示
3. 网络错误 → 验证错误处理
4. 大量消息 → 验证性能
```
