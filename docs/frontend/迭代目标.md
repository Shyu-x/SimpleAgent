## Agent 角色与分发策略 (Phase 5)

### 现状问题
1. **角色定义不一致** - 前后端各有一套定义，无统一标准
2. **预置角色池缺失** - 后端只有 5 个基本模板
3. **任务分发策略单一** - 只支持负载均衡，缺少技能匹配

### 需要实现的角色体系

| 角色 | 名称 | 核心能力 | 适用场景 |
|------|------|----------|----------|
| `researcher` | 技术调研员 | web_search, documentation, github | 技术选型、方案调研 |
| `architect` | 架构师 | system_design, pattern_selection | 系统设计、技术方案 |
| `coder` | 软件工程师 | code_generation, refactoring | 功能开发、代码实现 |
| `reviewer` | 代码审查员 | bug_detection, security_scan | Code Review、安全审查 |
| `qa_tester` | 测试工程师 | unit_test, e2e_test, performance | 测试用例生成、执行 |
| `devops` | 运维工程师 | deployment, monitoring, rollback | 部署、监控、故障恢复 |
| `documenter` | 文档工程师 | api_doc, readme, changelog | 文档编写、API 文档 |
| `data_analyst` | 数据分析师 | data_analysis, visualization | 数据处理、图表生成 |
| `supervisor` | 监控审查员 | quality_gate, progress_monitor | 质量门禁、进度跟踪 |
| `router` | 任务路由 | intent_classify, task_route | 意图识别、任务分流 |

### 任务分发策略

```typescript
interface DispatchStrategy {
  type: 'load_balance' | 'skill_match' | 'priority' | 'hybrid';
  
  // 技能匹配权重
  skillWeight: number;     // 0-1, 技能匹配重要性
  loadWeight: number;      // 0-1, 负载均衡重要性
  priorityWeight: number;   // 0-1, 优先级重要性
  
  // 历史成功率权重
  successRateWeight: number;
  
  // 备选策略
  fallbackStrategy: 'random' | 'round_robin' | 'least_loaded';
}
```

### 验收标准
- [ ] 统一 Agent 角色定义 (common/agent-roles.js)
- [ ] 至少 10 个预置 Agent 角色
- [ ] 支持 4 种分发策略 (负载均衡/技能匹配/优先级/混合)
- [ ] 前端 Agent 选择器支持角色筛选
- [ ] MissionControl 支持策略配置
