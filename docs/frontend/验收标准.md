# 前端验收标准

## 概述
本文档定义前端功能的验收条件和测试方法。

## 对话管理
| 功能 | 验收条件 | 测试方法 |
|------|----------|----------|
| 对话创建 | 点击新建生成空对话 | UI 测试 |
| 对话切换 | 点击对话 < 100ms 切换 | Performance API |
| 多窗口 | 最多 4 窗口并行 | 手动测试 |
| 对话删除 | 支持撤销操作 | UI 测试 |

## Agent 功能
| 功能 | 验收条件 | 测试方法 |
|------|----------|----------|
| Agent 路由 | /agent 页面正常加载 | E2E 测试 |
| 任务创建 | 3 步内完成 | UI 测试 |
| 性能监控 | 指标延迟 < 1s | 手动测试 |
| A2A 协作 | 状态实时同步 | SSE 连接测试 |

## 性能指标
| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 首屏加载 | < 1.5s | Lighthouse |
| 对话切换响应 | < 100ms | Performance API |
| 消息发送延迟 | < 200ms | Network 面板 |
| 内存占用 | < 200MB | DevTools |
