# 技术全景图 - 项目技术栈总览

## 项目架构概览

```
┌─────────────────────────────────────────────────────────────────┐
│                         前端 (Port 8080)                         │
│   React 19 + Next.js 15 + Zustand 5 + TypeScript               │
└─────────────────────────────────────────────────────────────────┘
                              ↕ HTTP/SSE
┌─────────────────────────────────────────────────────────────────┐
│                         后端 (Port 30000)                         │
```

## 核心流程

### 1. 聊天流程
```
用户输入 → ChatInput → chatStore → SSE 发送
                                            ↓
                                      后端 /api/chat
                                            ↓
                                      AgentEngine.run()
                                            ↓
                                      MiniMax API
                                            ↓
                                      SSE 流式响应
                                            ↓
前端渲染 ← chatStore 更新 ← EventSource 接收
```

### 2. 意图识别流程
```
用户消息 → IntentClassifier → 意图分类
                                    ↓
                    ┌───────────────┼───────────────┐
                    ↓               ↓               ↓
               knowledge       tool_call         chat
               (RAG检索)       (工具执行)       (直接回复)
```

### 3. RAG 检索流程
```
用户问题 → QueryRewrite → 改写问题
                            ↓
                     QueryDecompose → 拆分子问题
                            ↓
                    ┌────────┴────────┐
                    ↓                 ↓
              VectorSearch      KeywordSearch
                    ↓                 ↓
                    └────────┬────────┘
                             ↓
                         Reranker
                             ↓
                      CitationAssembler
                             ↓
                       组装最终答案
```

## 扩展点

### 1. 新增工具
```
1. 在 backend/src/services/tools/ 创建工具文件
2. 在 ToolRegistry 中注册
3. 在 frontend/src/lib/apiConfig.ts 配置前端调用
```

### 2. 新增模型
```
1. 在 services/model/clients/ 创建模型客户端
2. 在 ModelRouter 中添加路由策略
3. 更新 .env 配置
```

### 3. 新增 RAG 策略
```
1. 在 domain/rag/ 创建新策略类
2. 在 RAGService 中组合使用
3. 配置权重和阈值
```
