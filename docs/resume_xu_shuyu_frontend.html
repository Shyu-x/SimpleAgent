AI Chat 玩具 - 现代化 AI 对话平台前端
核心开发

  • 响应式布局架构：基于 Next.js App Router 实现移动端/平板/桌面三端适配，CSS Grid + Flexbox 布局，Tailwind CSS 响应式断点覆盖 <640px/640-1023px/>1024px
  • SSE 流式响应：基于 fetch + ReadableStream 实现流式聊天，打字机效果通过 onMessage 增量更新，支持 AbortController 取消请求，用户滚动时自动停止跟踪底部
  • 多模态输入：FileReader API 实现图片上传（base64预览），Web Audio API + MediaRecorder 实现语音录制（60秒超时限制），附件管理支持多文件预览与删除
  • 意图检测系统：7种意图类型（image_generation/vision/creative/task/tool_use/knowledge/conversation），多权重关键词匹配算法，300ms 防抖处理，高置信度(>=0.8)自动触发 Agent 模式

  • Zustand 三套Store架构：chatStore（全局聚合）/conversationStore（对话CRUD）/uiStore（UI状态），sessionStorage 安全持久化，API Key 不在前端持久化
  • 统一 API 客户端：拦截器模式（请求/响应/错误），指数退避重试（5xx错误），Bearer Token 认证，超时控制（默认30s），fetchStream SSE 流式封装
  • HITL 人机协作：8种确认类型（action/permission/data_access/external_call/file_operation/code_execution/cost_warning/sensitive_data），风险三级分级，倒计时进度条，键盘快捷键（Y确认/N取消），同类操作跳过
