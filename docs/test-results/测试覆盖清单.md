## 已知问题 (应用 Bug)

### 问题 1: `/api/rag/search` 返回 404
- **影响**: 全局 RAG 搜索功能不可用
- **分析**: 路由在 `rag.js` 中已定义 (`router.post('/search')`)，但访问时返回 404
- **可能原因**: 路由挂载问题或中间件冲突

### 问题 2: `/api/rag/fetch` 返回 404
- **影响**: URL 内容抓取功能不可用
- **分析**: 路由在 `rag.js` 中已定义 (`router.post('/fetch')`)，但访问时返回 404
- **可能原因**: 同上

### 问题 3: `/api/search` 根路径返回 404
- **影响**: 无法获取搜索服务基本信息
- **分析**: `search.js` 中定义了 `router.get('/')` 但返回 404
- **可能原因**: 路由挂载顺序问题，`searchEnhancedRoutes` 可能覆盖了 `searchRoutes`

### 问题 4: Web 搜索超时
- **影响**: 外部搜索 API 调用超时
- **分析**: 搜索请求需要 10+ 秒才能完成或超时
- **建议**: 增加超时时间或使用本地 Mock 数据进行测试

## 建议修复

### 1. 路由挂载问题
检查 `backend/src/index.js` 中的路由挂载顺序:
```javascript
// 当前顺序
app.use('/api/search', searchRoutes);
app.use('/api/search', searchEnhancedRoutes);

// 建议分开挂载
app.use('/api/search', searchRoutes);
app.use('/api/search/enhanced', searchEnhancedRoutes);
```

### 2. RAG 路由问题
检查 `backend/src/routes/rag.js` 的路由定义是否与挂载路径匹配。

### 3. 搜索超时问题
考虑在测试环境中使用 Mock 搜索结果，或增加超时配置。
