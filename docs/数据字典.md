## 一、数据字典概述

### 1.1 文档目的

本文档定义 AI Chat 玩具项目的所有数据模型，包括数据库表结构、字段定义、数据类型、约束条件等，为开发、测试和运维提供数据参考。

### 1.2 命名规范

| 规范 | 说明 | 示例 |
|------|------|------|
| 表名 | 小写下划线命名，复数形式 | `conversations`, `messages` |
| 字段名 | 小写下划线命名 | `conversation_id`, `created_at` |
| 主键 | `id`，UUID 格式 | `uuid`, `cuid` |
| 外键 | `{表名}_id` | `conversation_id`, `user_id` |
| 时间戳 | `{action}_at` | `created_at`, `updated_at` |
| 布尔值 | `is_{属性}` 或 `{属性}_flag` | `is_active`, `deleted_flag` |

### 1.3 数据类型规范

| 类型 | PostgreSQL | 说明 |
|------|------------|------|
| 短文本 | VARCHAR(255) | 常规字符串 |
| 长文本 | TEXT | 无限制文本 |
| 枚举 | VARCHAR(50) | 受限字符串 |
| 整数 | INTEGER | 32 位整数 |
| 长整数 | BIGINT | 64 位整数 |
| 浮点数 | DECIMAL(10,2) | 精确小数 |
| 布尔值 | BOOLEAN | true/false |
| JSON | JSONB | JSON 对象 |
| 时间戳 | TIMESTAMP WITH TIME ZONE | UTC 时间 |
| UUID | UUID | 通用唯一标识符 |

### 1.4 通用字段

所有表包含以下通用字段:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键，唯一标识 |
| created_at | TIMESTAMP | 创建时间 (UTC) |
| updated_at | TIMESTAMP | 更新时间 (UTC) |
| deleted_at | TIMESTAMP | 软删除时间 (可选) |

## 二、核心数据模型

### 2.1 用户表 (users)

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(100) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    display_name VARCHAR(100),
    avatar_url VARCHAR(500),
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'banned')),
    role VARCHAR(20) DEFAULT 'user' CHECK (role IN ('user', 'admin', 'super_admin')),
    last_login_at TIMESTAMP WITH TIME ZONE,
    last_login_ip INET,
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    deleted_at TIMESTAMP WITH TIME ZONE
);

CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_status ON users(status);
CREATE INDEX idx_users_created_at ON users(created_at);
```

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK, DEFAULT | 用户唯一标识 |
| username | VARCHAR(100) | UNIQUE, NOT NULL | 用户名 |
| email | VARCHAR(255) | UNIQUE, NOT NULL | 邮箱 |
| password_hash | VARCHAR(255) | NOT NULL | 密码哈希 (bcrypt) |
| display_name | VARCHAR(100) | - | 显示名称 |
| avatar_url | VARCHAR(500) | - | 头像 URL |
| status | VARCHAR(20) | CHECK | 状态: active/inactive/banned |
| role | VARCHAR(20) | CHECK | 角色: user/admin/super_admin |
| last_login_at | TIMESTAMP | - | 最后登录时间 |
| last_login_ip | INET | - | 最后登录 IP |
| metadata | JSONB | DEFAULT | 扩展元数据 |
| created_at | TIMESTAMP | DEFAULT | 创建时间 |
| updated_at | TIMESTAMP | DEFAULT | 更新时间 |
| deleted_at | TIMESTAMP | - | 软删除时间 |

## 三、对话相关数据

### 3.1 会话表 (conversations)

```sql
CREATE TABLE conversations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(255),
    model_id VARCHAR(100) NOT NULL,
    system_prompt TEXT,
    temperature DECIMAL(3,2) DEFAULT 0.7,
    max_tokens INTEGER DEFAULT 4000,
    top_p DECIMAL(3,2) DEFAULT 0.9,
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'archived', 'deleted')),
    message_count INTEGER DEFAULT 0,
    total_tokens BIGINT DEFAULT 0,
    last_message_at TIMESTAMP WITH TIME ZONE,
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    deleted_at TIMESTAMP WITH TIME ZONE
);

CREATE INDEX idx_conversations_user_id ON conversations(user_id);
CREATE INDEX idx_conversations_status ON conversations(status);
CREATE INDEX idx_conversations_created_at ON conversations(created_at DESC);
CREATE INDEX idx_conversations_last_message_at ON conversations(last_message_at DESC);
```

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 会话唯一标识 |
| user_id | UUID | FK, NOT NULL | 所属用户 |
| title | VARCHAR(255) | - | 会话标题 |
| model_id | VARCHAR(100) | NOT NULL | 使用的模型 ID |
| system_prompt | TEXT | - | 系统提示词 |
| temperature | DECIMAL(3,2) | DEFAULT | 温度参数 (0-1) |
| max_tokens | INTEGER | DEFAULT | 最大 Token 数 |
| top_p | DECIMAL(3,2) | DEFAULT | Top-P 参数 |
| status | VARCHAR(20) | CHECK | 状态 |
| message_count | INTEGER | DEFAULT | 消息数量 |
| total_tokens | BIGINT | DEFAULT | 总 Token 消耗 |
| last_message_at | TIMESTAMP | - | 最后消息时间 |
| metadata | JSONB | DEFAULT | 扩展元数据 |

### 3.2 消息表 (messages)

```sql
CREATE TABLE messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
    role VARCHAR(20) NOT NULL CHECK (role IN ('user', 'assistant', 'system', 'tool')),
    content TEXT NOT NULL,
    model VARCHAR(100),
    input_tokens INTEGER,
    output_tokens INTEGER,
    total_tokens INTEGER GENERATED ALWAYS AS (
        COALESCE(input_tokens, 0) + COALESCE(output_tokens, 0)
    ) STORED,
    reasoning_content TEXT,
    tool_calls JSONB,
    tool_results JSONB,
    citations JSONB,
    error_message TEXT,
    latency_ms INTEGER,
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    deleted_at TIMESTAMP WITH TIME ZONE
);

CREATE INDEX idx_messages_conversation_id ON messages(conversation_id);
CREATE INDEX idx_messages_role ON messages(role);
CREATE INDEX idx_messages_created_at ON messages(created_at);
CREATE INDEX idx_messages_conversation_created ON messages(conversation_id, created_at);
```

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 消息唯一标识 |
| conversation_id | UUID | FK, NOT NULL | 所属会话 |
| role | VARCHAR(20) | CHECK, NOT NULL | 角色 |
| content | TEXT | NOT NULL | 消息内容 |
| model | VARCHAR(100) | - | 使用的模型 |
| input_tokens | INTEGER | - | 输入 Token 数 |
| output_tokens | INTEGER | - | 输出 Token 数 |
| total_tokens | INTEGER | GENERATED | 总 Token 数 |
| reasoning_content | TEXT | - | 思维链内容 (MiniMax) |
| tool_calls | JSONB | - | 工具调用列表 |
| tool_results | JSONB | - | 工具执行结果 |
| citations | JSONB | - | 引用来源 |
| error_message | TEXT | - | 错误信息 |
| latency_ms | INTEGER | - | 响应延迟 (毫秒) |
| metadata | JSONB | DEFAULT | 扩展元数据 |

**tool_calls JSONB 结构**:
```json
[
  {
    "id": "call_abc123",
    "type": "function",
    "function": {
      "name": "web_search",
      "arguments": "{\"query\": \"...\"}"
    }
  }
]
```

**tool_results JSONB 结构**:
```json
[
  {
    "tool_call_id": "call_abc123",
    "tool": "web_search",
    "input": {"query": "..."},
    "output": "搜索结果...",
    "is_error": false,
    "latency_ms": 150
  }
]
```

**citations JSONB 结构**:
```json
[
  {
    "document_id": "doc_abc123",
    "chunk_id": "chunk_001",
    "score": 0.92,
    "content": "引用内容...",
    "metadata": {"source": "file.pdf", "page": 5}
  }
]
```

## 四、Agent 相关数据

### 4.1 Agent 表 (agents)

```sql
CREATE TABLE agents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    model_id VARCHAR(100) NOT NULL,
    system_prompt TEXT,
    tools JSONB DEFAULT '[]',
    max_iterations INTEGER DEFAULT 10,
    timeout_ms INTEGER DEFAULT 60000,
    temperature DECIMAL(3,2) DEFAULT 0.7,
    memory_enabled BOOLEAN DEFAULT true,
    memory_window INTEGER DEFAULT 10,
    rag_enabled BOOLEAN DEFAULT false,
    checkpoint_enabled BOOLEAN DEFAULT true,
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive', 'archived')),
    stats JSONB DEFAULT '{"total_runs": 0, "success_rate": 0, "avg_latency": 0}',
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    deleted_at TIMESTAMP WITH TIME ZONE
);

CREATE INDEX idx_agents_user_id ON agents(user_id);
CREATE INDEX idx_agents_status ON agents(status);
CREATE INDEX idx_agents_model_id ON agents(model_id);
```

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | Agent 唯一标识 |
| user_id | UUID | FK, NOT NULL | 所属用户 |
| name | VARCHAR(100) | NOT NULL | Agent 名称 |
| description | TEXT | - | Agent 描述 |
| model_id | VARCHAR(100) | NOT NULL | 使用的模型 |
| system_prompt | TEXT | - | 系统提示词 |
| tools | JSONB | DEFAULT | 可用工具列表 |
| max_iterations | INTEGER | DEFAULT | 最大迭代次数 |
| timeout_ms | INTEGER | DEFAULT | 超时时间 (毫秒) |
| temperature | DECIMAL(3,2) | DEFAULT | 温度参数 |
| memory_enabled | BOOLEAN | DEFAULT | 是否启用记忆 |
| memory_window | INTEGER | DEFAULT | 记忆窗口大小 |
| rag_enabled | BOOLEAN | DEFAULT | 是否启用 RAG |
| checkpoint_enabled | BOOLEAN | DEFAULT | 是否启用检查点 |
| status | VARCHAR(20) | CHECK | 状态 |
| stats | JSONB | DEFAULT | 统计信息 |

**tools JSONB 结构**:

### 4.2 Agent 执行记录表 (agent_runs)

```sql
CREATE TABLE agent_runs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    agent_id UUID NOT NULL REFERENCES agents(id) ON DELETE CASCADE,
    conversation_id UUID REFERENCES conversations(id) ON DELETE SET NULL,
    input TEXT NOT NULL,
    output TEXT,
    status VARCHAR(20) DEFAULT 'running' CHECK (status IN ('running', 'completed', 'failed', 'cancelled', 'timeout')),
    iterations INTEGER DEFAULT 0,
    tool_calls JSONB DEFAULT '[]',
    checkpoints JSONB DEFAULT '[]',
    error_code VARCHAR(50),
    error_message TEXT,
    start_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    end_at TIMESTAMP WITH TIME ZONE,
    duration_ms INTEGER,
    total_tokens BIGINT DEFAULT 0,
    metadata JSONB DEFAULT '{}',
    deleted_at TIMESTAMP WITH TIME ZONE
);

CREATE INDEX idx_agent_runs_agent_id ON agent_runs(agent_id);
CREATE INDEX idx_agent_runs_status ON agent_runs(status);
CREATE INDEX idx_agent_runs_start_at ON agent_runs(start_at DESC);
```

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 执行记录唯一标识 |
| agent_id | UUID | FK, NOT NULL | 所属 Agent |
| conversation_id | UUID | FK | 关联会话 |
| input | TEXT | NOT NULL | 输入内容 |
| output | TEXT | - | 输出内容 |
| status | VARCHAR(20) | CHECK | 执行状态 |
| iterations | INTEGER | DEFAULT | 迭代次数 |
| tool_calls | JSONB | DEFAULT | 工具调用记录 |
| checkpoints | JSONB | DEFAULT | 检查点数据 |
| error_code | VARCHAR(50) | - | 错误码 |
| error_message | TEXT | - | 错误信息 |
| start_at | TIMESTAMP | DEFAULT | 开始时间 |
| end_at | TIMESTAMP | - | 结束时间 |
| duration_ms | INTEGER | - | 执行时长 (毫秒) |
| total_tokens | BIGINT | DEFAULT | 总 Token 消耗 |

### 5.3 分块表 (chunks)

```sql
CREATE TABLE chunks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    document_id UUID NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    content_hash VARCHAR(64) NOT NULL,
    chunk_index INTEGER NOT NULL,
    vector_id VARCHAR(100),
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),

    UNIQUE(document_id, content_hash)
);

CREATE INDEX idx_chunks_document_id ON chunks(document_id);
CREATE INDEX idx_chunks_content_hash ON chunks(content_hash);
CREATE INDEX idx_chunks_chunk_index ON chunks(chunk_index);
```

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | UUID | PK | 分块唯一标识 |
| document_id | UUID | FK, NOT NULL | 所属文档 |

## 八、Redis 数据结构

### 8.1 会话缓存

```
Key: session:{conversation_id}
Type: Hash
TTL: 7 天

Fields:
- messages: JSON string (最近 N 条消息)
- context: JSON string (对话上下文)
- last_access: timestamp
```

### 8.2 用户会话列表

```
Key: user:{user_id}:conversations
Type: Sorted Set
Score: last_message_at timestamp
Member: conversation_id

TTL: 永久
```

### 8.3 速率限制

```
Key: ratelimit:{type}:{id}:{window}
Type: String (counter)
TTL: window 秒

Value: 请求计数
```

### 8.4 Token 使用统计

```
Key: usage:{user_id}:{date}
Type: Hash
TTL: 90 天

Fields:
- total_tokens: 总消耗
- input_tokens: 输入消耗
- output_tokens: 输出消耗
- request_count: 请求次数
```

### 8.5 Agent 执行状态

```
Key: agent_run:{run_id}
Type: Hash
TTL: 1 小时

Fields:
- status: running/completed/failed
- state: JSON string
- progress: 百分比
- iteration: 当前迭代
```
