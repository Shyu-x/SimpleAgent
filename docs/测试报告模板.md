## 一、测试报告概述

### 1.1 测试报告目的

本文档为 AI Chat 玩具项目提供标准化的测试报告模板，确保测试结果可追溯、可比较、可重复。

### 1.2 测试类型定义

| 测试类型 | 目标 | 执行频率 | 负责人 |
|---------|------|---------|--------|
| 单元测试 | 验证最小可测试单元 | 每次提交 | 开发工程师 |
| 集成测试 | 验证模块间交互 | 每日构建 | 测试工程师 |
| E2E 测试 | 验证完整业务流程 | 每周完整测试 | QA 团队 |
| 性能测试 | 验证性能指标 | 每次发布前 | 性能测试工程师 |
| 安全测试 | 验证安全性 | 每月 + 每次发布前 | 安全工程师 |

### 1.3 测试通过标准

| 测试类型 | 通过标准 |
|---------|---------|
| 单元测试 | 通过率 >= 95%，覆盖率 >= 80% |
| 集成测试 | 通过率 100%，无高危缺陷遗留 |
| E2E 测试 | 核心流程通过率 100% |
| 性能测试 | 所有指标达到预设目标 |
| 安全测试 | 无高危/严重漏洞 |

### 单元测试示例

```javascript
// backend/tests/unit/chatService.test.js

const { describe, it, expect, beforeEach, jest } = require('@jest/globals');

describe('ChatService 单元测试', () => {
  let chatService;
  let mockChatModelClient;
  let mockMemoryService;

  beforeEach(() => {
    // 初始化 Mock
    mockChatModelClient = {
      chat: jest.fn(),
      stream: jest.fn()
    };
    mockMemoryService = {
      addMessage: jest.fn(),
      getMessages: jest.fn()
    };

    chatService = new ChatService({
      chatModelClient: mockChatModelClient,
      memoryService: mockMemoryService
    });
  });

  describe('sendMessage', () => {
    it('P0-正常发送消息应返回响应', async () => {
      // 准备
      const message = '你好';
      const mockResponse = { content: '你好，我是 AI Chat' };
      mockChatModelClient.chat.mockResolvedValue(mockResponse);
      mockMemoryService.getMessages.mockResolvedValue([]);

      // 执行
      const result = await chatService.sendMessage({ message });

      // 验证
      expect(result).toBeDefined();
      expect(result.content).toBe('你好，我是 AI Chat');
      expect(mockChatModelClient.chat).toHaveBeenCalled();
    });

    it('P1-空消息应抛出错误', async () => {
      // 准备
      const message = '';

      // 执行 & 验证
      await expect(chatService.sendMessage({ message }))
        .rejects
        .toThrow('消息内容不能为空');
    });

    it('P2-消息过长应抛出错误', async () => {
      // 准备
      const message = 'a'.repeat(100001);

      // 执行 & 验证
      await expect(chatService.sendMessage({ message }))
        .rejects
        .toThrow('消息长度不能超过 100000 字符');
    });

    it('P1-Model API 失败应重试', async () => {
      // 准备
      const message = '你好';
      mockChatModelClient.chat
        .mockRejectedValueOnce(new Error('Network error'))
        .mockRejectedValueOnce(new Error('Network error'))
        .mockResolvedValue({ content: 'Response' });

      // 执行
      const result = await chatService.sendMessage({ message });

      // 验证
      expect(result).toBeDefined();
      expect(mockChatModelClient.chat).toHaveBeenCalledTimes(3);
    });

    it('P2-会话不存在应创建新会话', async () => {
      // 准备
      const conversationId = null;
      const message = '你好';
      mockMemoryService.getMessages.mockRejectedValue(new Error('Not found'));

      // 执行
      const result = await chatService.sendMessage({ conversationId, message });

      // 验证
      expect(result.conversationId).toBeDefined();
    });
  });

  describe('getConversationHistory', () => {
    it('P0-获取会话历史应返回消息列表', async () => {
      // 准备
      const conversationId = 'conv_123';
      const mockMessages = [
        { id: '1', role: 'user', content: '你好' },
        { id: '2', role: 'assistant', content: '你好，我是 AI' }
      ];
      mockMemoryService.getMessages.mockResolvedValue(mockMessages);

      // 执行
      const result = await chatService.getConversationHistory({ conversationId });

      // 验证
      expect(result).toHaveLength(2);
      expect(result[0].role).toBe('user');
    });

    it('P1-会话不存在应返回空列表', async () => {
      // 准备
      const conversationId = 'non_existent';
      mockMemoryService.getMessages.mockResolvedValue([]);

      // 执行
      const result = await chatService.getConversationHistory({ conversationId });

      // 验证
      expect(result).toHaveLength(0);
    });
  });
});
```

// frontend/tests/e2e/chat.spec.ts
import { test, expect } from '@playwright/test';

test.describe('对话功能 E2E 测试', () => {
  test.beforeEach(async ({ page }) => {
    // 访问首页
    await page.goto('/');
    // 等待页面加载
    await page.waitForLoadState('networkidle');
  });

  test('P0-用户可以发送消息并收到回复', async ({ page }) => {
    // 1. 输入消息
    const input = page.locator('[data-testid="message-input"]');

## 七、测试报告填写指南

### 7.1 填写规范

1. **所有字段必须填写**，无内容填 "N/A"
2. **日期格式**: YYYY-MM-DD
3. **时间格式**: YYYY-MM-DD HH:MM:SS
4. **数字精度**: 百分比保留 2 位小数
5. **缺陷 ID**: 使用统一格式 (如 BUG-XXX)

### 7.2 状态定义

| 状态 | 定义 |
|------|------|
| PASS | 测试通过 |
| FAIL | 测试失败 |
| BLOCKED | 测试被阻塞 |
| SKIP | 测试跳过 |
| PASS (有条件) | 有条件通过 |

### 7.3 优先级定义

| 优先级 | 定义 | 响应时间 |
|--------|------|---------|
| P0 | 核心功能，必须通过 | 立即 |
| P1 | 主要功能，影响较大 | 24 小时 |
| P2 | 次要功能，影响较小 | 72 小时 |
| P3 | 轻微问题 | 7 天 |

### 7.4 严重程度定义

| 等级 | 定义 | 影响 |
|------|------|------|
| S0/严重 | 系统不可用 | 核心功能完全失效 |
| S1/高 | 核心功能受损 | 严重影响业务 |
| S2/中 | 功能部分受损 | 影响用户体验 |
| S3/低 | 轻微问题 | 几乎不影响使用 |
