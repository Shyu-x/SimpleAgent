# 环境管理规范

## 概述

SimpleAgent 项目涉及 **Node.js** 环境，需要通过版本管理工具确保开发、构建、部署环境一致性。

---

## Node.js 环境管理

### 版本要求

| 项目 | 版本 | 说明 |
|------|------|------|
| Node.js | ≥18.0.0, <25.0.0 | LTS 版本，推荐 v20.x |
| pnpm | ≥8.0.0 | 项目默认包管理器 |

### 管理工具

**必须使用 nvm (Node Version Manager) 管理 Node 版本**

```bash
# 安装 nvm (如果未安装)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# 安装指定 Node 版本
nvm install 20
nvm use 20
nvm alias default 20

# 验证
node --version  # 期望: v20.x.x
pnpm --version  # 期望: ≥10.x.x
```

### 版本锁定文件

**`.nvmrc`** - Node 版本锁定文件

```bash
# 在项目根目录创建
echo "20" > .nvmrc

# 切换到指定版本
nvm use  # 读取 .nvmrc 并切换
```

### package.json engines 约束

```json
{
  "engines": {
    "node": ">=18.0.0 <25.0.0",
    "pnpm": ">=8.0.0"
  }
}
```

## pnpm 包管理器

### 为什么使用 pnpm

- **速度快**: 依赖安装比 npm 快 2-3 倍
- **节省空间**: 硬链接机制，相同依赖不重复安装
- **严格隔离**: 防止幽灵依赖问题

### pnpm 命令

```bash
# 安装依赖
pnpm install

# 添加依赖
pnpm add <package>

# 移除依赖
pnpm remove <package>

# 更新依赖
pnpm update

# 查看依赖状态
pnpm list

# 运行脚本
pnpm dev
pnpm build
pnpm test
```

## 环境初始化流程

### 1. 克隆项目后

```bash
# 切换到正确 Node 版本
nvm use  # 读取 .nvmrc

# 安装 pnpm (如果未安装)
npm install -g pnpm

# 安装依赖
cd backend && pnpm install
cd ../frontend && pnpm install
```

### 2. 启动服务

```bash
# 后端 (端口 30000)
cd backend && pnpm dev

# 前端 (端口 30001)
cd frontend && pnpm dev
```

### 3. 使用 PM2 管理进程

```bash
# 安装 PM2 (全局)
pnpm add -g pm2

# 使用 ecosystem.config.js 启动
pm2 start ecosystem.config.js

# 查看状态
pm2 list

# 查看日志
pm2 logs ai-chat-backend
pm2 logs ai-chat-frontend

# 重启
pm2 restart ai-chat-backend
pm2 restart ai-chat-frontend

# 停止
pm2 stop ai-chat-backend
pm2 stop ai-chat-frontend
```

## 故障排除

### Node 版本不对

```bash
# 检查当前版本
node --version

# 切换到正确版本
nvm use

# 如果 .nvmrc 没有匹配版本
nvm install && nvm use
```

### pnpm 报错

```bash
# 清除缓存
pnpm store prune

# 重新安装
rm -rf node_modules
pnpm install
```

### PM2 进程无法启动

```bash
# 查看错误日志
pm2 logs --lines 50

# 重置 PM2
pm2 reset all
pm2 delete all
pm2 start ecosystem.config.js
```

## 多项目工作区

项目根目录包含多个子项目，使用 pnpm workspace：

```bash
# 根目录 pnpm-workspace.yaml
packages:
  - 'backend'
  - 'frontend'

# 安装所有子项目依赖
pnpm install

# 从根目录运行脚本
pnpm --filter @simpleagent/backend dev
pnpm --filter @simpleagent/frontend dev
```

## Vercel 部署

详细部署指南请参考 [VERCEL_DEPLOY.md](./VERCEL_DEPLOY.md)

### 前端快速部署

1. 访问 [vercel.com](https://vercel.com) 导入 `Shyu-x/SimpleAgent`
2. 配置构建:
   - Build Command: `pnpm build`
   - Output Directory: `.next`
   - Install Command: `pnpm install`
3. 添加环境变量: `NEXT_PUBLIC_BACKEND_URL=https://your-backend-url.com`
