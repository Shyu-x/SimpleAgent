# 统一错误码体系 v2.0

## 概述
跨三个后端的统一错误码体系，支持快速定位问题类型、影响范围和解决方案。

## 错误码范围: 1000-9999

## 错误类型分类

| 类型 | 范围 | 说明 |
|------|------|------|
| VALIDATION | 1000-1999 | 参数校验类 |
| AUTH | 2000-2999 | 认证授权类 |
| AGENT | 3000-3999 | Agent执行类 |
| RAG | 4000-4999 | 知识检索类 |
| TOOL | 5000-5999 | 工具调用类 |
| INTERNAL | 6000-6999 | 系统异常类 |

## 三端适配状态

| 后端 | 错误类 | ErrorCodes | Errors工厂 | 错误处理中间件 | 状态 |
|------|--------|------------|------------|---------------|------|
| backend (Express) | `AppError.js` | ✅ | ✅ | `errorHandler.js` | ✅ 已完成 |
| backend-nest (NestJS) | `app-error.ts` | ✅ | ✅ | `all-exceptions.filter.ts` | ✅ 已完成 |
| backend-go (Go) | `errors.go` | ✅ | ✅ | `error_handler.go` | ✅ 已完成 |

### 后端错误处理中间件详情

#### Backend Express
- **错误处理中间件**: `backend/src/middleware/errorHandler.js`
- **功能**: 统一错误处理、404路由、日志记录
- **特性**: 支持 AppError、ValidationError、JSON解析错误、MongoDB错误、JWT错误

#### Backend NestJS
- **全局异常过滤器**: `backend-nest/src/common/filters/all-exceptions.filter.ts`
- **HTTP异常过滤器**: `backend-nest/src/common/filters/http-exception.filter.ts`
- **功能**: 统一异常处理、错误码映射、日志记录
- **特性**: 支持 AppError、HttpException 自动转换

#### Backend Go
- **错误处理中间件**: `backend-go/internal/middleware/error_handler.go`
- **中间件栈**: `backend-go/internal/middleware/middleware.go` (已集成)
- **功能**: Panic恢复、错误处理、404路由、日志记录
- **特性**: 支持 AppError、结构化JSON日志

### 错误响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 请求是否成功 (false) |
| error.code | number | 错误码 (1000-9999) |
| error.type | string | 错误类型 (6种) |
| error.message | string | 错误信息 |
| error.details | object | 详细错误信息 (可选) |
| error.level | number | 错误级别 (0-3) |
| error.requestId | string | 请求ID (链路追踪) |
| error.timestamp | string | 时间戳 (ISO 8601) |
| error.stack | string | 堆栈信息 (仅开发环境) |
