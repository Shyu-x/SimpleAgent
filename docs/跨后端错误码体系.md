> **版本**: v1.0.0
> **日期**: 2026-04-06
> **范围**: backend / backend-nest / backend-go

---

## 一、错误码架构

### 1.1 设计原则

- **范围**: 1000-9999 (共9000个错误码)
- **格式**: 纯数字，便于日志检索和监控告警
- **分类**: 6大类，按域划分，互不冲突
- **可扩展**: 预留空间，支持未来新增子类

### 1.2 错误码分类表

| 类型 | 范围 | 说明 | HTTP状态 |
|------|------|------|----------|
| **VALIDATION** | 1000-1999 | 参数校验、输入验证 | 400 |
| **AUTH** | 2000-2999 | 认证授权、权限控制 | 401/403 |
| **AGENT** | 3000-3999 | Agent执行、意图路由、任务编排 | 400/500 |
| **RAG** | 4000-4999 | 知识检索、文档摄取、向量存储 | 400/500 |
| **TOOL** | 5000-5999 | 工具注册、执行、调用 | 400/500 |
| **INTERNAL** | 6000-6999 | 系统级错误、数据库、网络 | 500/503 |

## 三、统一响应格式

### 3.1 成功响应

```json
{
  "success": true,
  "data": { ... },
  "requestId": "req_123456789"
}
```

### 3.2 错误响应

```json
{
  "success": false,
  "error": {
    "code": 3001,
    "type": "AGENT",
    "message": "意图分类失败",
    "detail": "不支持的意图类型: unknown_intent",
    "requestId": "req_123456789",
    "timestamp": "2026-04-06T10:30:00.000Z"
  }
}
```

### 3.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| success | boolean | 是 | 请求是否成功 |
| error.code | number | 否 | 错误码 (1000-9999) |
| error.type | string | 否 | 错误类型 (VALIDATION/AUTH/AGENT/RAG/TOOL/INTERNAL) |
| error.message | string | 是 | 错误消息 (用户友好) |
| error.detail | string | 否 | 错误详情 (开发环境) |
| error.requestId | string | 否 | 请求追踪ID |
| error.timestamp | string | 是 | 错误发生时间 (ISO8601) |

## 四、错误类工厂函数

### 4.1 Node.js (backend / backend-nest)

```javascript
// 错误类使用 AppError
const error = new AppError(1001, '缺少必需参数: userId');
const error = AppError.validationError('userId', '缺少必需参数');
const error = AppError.notFound('Session');
const error = AppError.unauthorized('Token已过期');
const error = AppError.agentError('INTENT_CLASSIFY_FAILED', '意图分类失败');
const error = AppError.ragError('RETRIEVAL_FAILED', '检索失败');
const error = AppError.toolError('TOOL_TIMEOUT', '工具执行超时');
```

### 4.2 Go (backend-go)

```go
// 使用 errors 包
err := errors.InvalidParam("userId", "参数不能为空")
err := errors.NotFound("Session", "会话不存在")
err := errors.Unauthorized("token expired")
err := errors.AgentError(errors.ErrIntentClassify, "意图分类失败")
err := errors.RAGError(errors.ErrRetrievalFailed, "检索无结果")
err := errors.ToolError("search", errors.ErrToolTimeout, "搜索工具超时")
```

## 六、监控与告警

### 6.1 错误级别定义

| 级别 | 说明 | 告警 |
|------|------|------|
| INFO | 信息 | 否 |
| WARNING | 警告 | 可选 |
| ERROR | 错误 | 是 |
| CRITICAL | 严重 | 是 |

### 6.2 需告警的错误码

- 6xxx (INTERNAL): 所有系统级错误 → CRITICAL
- 5xxx (TOOL): 工具系统错误 → ERROR
- 4xxx (RAG): RAG系统错误 → ERROR
- 3xxx (AGENT): Agent执行错误 → WARNING
- 2xxx (AUTH): 认证授权错误 → WARNING
- 1xxx (VALIDATION): 参数校验错误 → INFO
