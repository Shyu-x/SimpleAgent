## 一、设计原则

### 1.1 错误码结构

```
格式: 纯数字 1000-9999
长度: 4 位数字
分类: 第 1 位表示大类 (1-6)
序列: 后 3 位表示具体错误
```

### 1.2 错误类型

| 类型 | 范围 | 说明 | HTTP 状态码 |
|------|------|------|-------------|
| VALIDATION | 1000-1999 | 参数校验错误 | 400 |
| AUTH | 2000-2999 | 认证授权错误 | 401/403 |
| AGENT | 3000-3999 | Agent 执行错误 | 400/500/504 |
| RAG | 4000-4999 | 知识检索错误 | 400/404/500 |
| TOOL | 5000-5999 | 工具调用错误 | 400/404/500/504 |
| INTERNAL | 6000-6999 | 系统内部错误 | 500/502/503/504/429 |

## 三、错误响应格式

### 3.1 统一响应结构

所有 API 响应均使用以下格式：

```json
{
  "success": true|false,
  "data": <any>,
  "error": <object|null>
}
```

### 3.2 错误响应示例

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": 3004,
    "type": "AGENT",
    "message": "Agent 执行超时",
    "details": {
      "agentId": "agent_xxx",
      "timeout": 30000
    },
    "requestId": "req_abc123def456",
    "timestamp": "2026-04-06T10:30:00.000Z"
  }
}
```

### 3.3 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| success | boolean | 是 | 请求是否成功 |
| data | any | 是 | 成功时返回数据，错误时为 null |
| error | object | 否 | 错误详情，成功时为 null |
| error.code | number | 是 | 数字错误码 (1000-9999) |
| error.type | string | 是 | 错误类型 (VALIDATION/AUTH/AGENT/RAG/TOOL/INTERNAL) |
| error.message | string | 是 | 错误消息（用户友好） |
| error.details | object | 否 | 调试用详细信息 |
| error.requestId | string | 否 | 链路追踪 ID |
| error.timestamp | string | 是 | 错误发生时间 (ISO 8601) |

### 3.4 成功响应示例

```json
{
  "success": true,
  "data": {
    "result": "xxx"
  },
  "error": null
}
```

### 4.1 可恢复错误 (RECOVERABLE)

可通过降级、重试或备用方案恢复的错误：

| 类型 | 错误码 | 说明 |
|------|--------|------|
| TOOL | 5003, 5004, 5007 | 工具执行失败、超时、未实现 |
| TOOL | 5101, 5102 | MCP 连接失败、请求失败 |
| RAG | 4003, 4004, 4200, 4201, 4202 | 检索失败、重排序失败、搜索失败 |
| RAG | 4103 | 向量化失败 |
| AGENT | 3004 | 执行超时 |
| AGENT | 3201, 3202 | 记忆保存/召回失败 |
| INTERNAL | 6001, 6002, 6003 | 服务不可用、超时、网络错误 |
| INTERNAL | 6100, 6101, 6102 | 数据库错误、连接失败、查询失败 |
| INTERNAL | 6200, 6202 | 缓存错误、Redis 连接失败 |

## 五、使用规范

### 5.1 后端使用示例

```javascript
// 引入统一错误类
const AppError = require('./common/errors/AppError');

// 抛出预定义错误
throw new AppError(AppError.CODES.MISSING_PARAM);

// 自定义错误消息
throw new AppError(AppError.CODES.AGENT_ERROR.code, 'Agent 执行失败');

// 工厂方法
throw AppError.validationError('message', '消息内容不能为空');
throw AppError.notFound('会话');
throw AppError.unauthorized('请先登录');
throw AppError.rateLimit('请求过于频繁');

// 域特定工厂
throw AppError.agentError('EXECUTION_TIMEOUT', 'Agent 执行超时');
throw AppError.ragError('RETRIEVAL_FAILED', '检索失败');
throw AppError.toolError('TOOL_TIMEOUT', '工具执行超时');

// 添加详情
const error = new AppError(AppError.CODES.INVALID_PARAM.code, '参数错误');
error.addDetails({ field: 'modelId', reason: 'invalid value' });
throw error;
```

### 5.2 全局错误中间件

```javascript
// middleware/errorHandler.js
const AppError = require('../common/errors/AppError');

function errorHandler(err, req, res, next) {
  // AppError 直接处理
  if (err instanceof AppError) {
    err.setRequestId(req.requestId);
    return res.status(err.status).json(err.toResponse());
  }

  // 未知错误
  const internalError = new AppError(
    AppError.CODES.INTERNAL_ERROR.code,
    '内部服务器错误'
  );
  internalError.setRequestId(req.requestId);

  if (process.env.NODE_ENV !== 'production') {
    internalError.addDetails({ stack: err.stack });
  }

  return res.status(500).json(internalError.toResponse());
}

module.exports = errorHandler;
```

### 5.3 前端错误处理

```typescript
// lib/apiClient.ts
class ApiError extends Error {
  code: number;
  type: string;
  details?: object;
  requestId?: string;

  constructor(code: number, type: string, message: string, details?: object) {
    super(message);
    this.name = 'ApiError';
    this.code = code;
    this.type = type;
    this.details = details;
  }
}

async function handleResponse<T>(response: Response): Promise<T> {
  const data = await response.json();

  if (data.success === false && data.error) {
    const error = new ApiError(
      data.error.code,
      data.error.type,
      data.error.message,
      data.error.details
    );
    error.requestId = data.error.requestId;
    throw error;
  }

  return data.data;
}

// 使用示例
try {
  const result = await apiClient.post('/api/chat/send', { message });
} catch (error) {
  if (error instanceof ApiError) {
    switch (error.type) {
      case 'VALIDATION':
        showToast(`参数错误: ${error.message}`);
        break;
      case 'AUTH':
        redirectToLogin();
        break;
      case 'AGENT':
        if (error.code === 3004) {
          showToast('Agent 执行超时，请重试');
        }
        break;
      case 'RATE_LIMIT_EXCEEDED':
        showToast('请求过于频繁，请稍后重试');
        break;
      default:
        showToast(error.message);
    }
    console.error(`[${error.requestId}] ${error.type} ${error.code}: ${error.message}`);
  }
}
```
