### 2.1 图片生成功能 ✅

**测试指令**: "帮我画一只可爱的猫咪"

**后端API**:
- 端点: `POST /api/minimax/image`
- 模型: `image-01`
- 支持: 1:1, 16:9, 9:16, 3:4, 4:3 比例

**前端实现**:
- 意图检测: `useIntentDetection.ts` 检测 `image_generation` 关键词
- 自动调用: MiniMax Image-01 API
- 渲染: 图片URL在消息中显示

**代码位置**:
```
后端: backend/src/routes/minimaxMcp.js (26-112行)
前端意图: frontend/src/hooks/useIntentDetection.ts
API调用: frontend/src/lib/api.ts
```
