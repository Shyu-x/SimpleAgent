# React前端 - 5分钟跑通

## 这是什么？
Next.js 15 + React 19 构建的现代化 AI 对话前端应用
- 端口：8080
- 特性：SSE流式响应、打字机效果、多窗口聊天

## 环境准备（极简）
- Node.js 18+
- npm 或 yarn
- Git

## 第一步：克隆项目（1分钟）
```bash
git clone <仓库地址>
cd chat玩具
```

## 第二步：安装依赖（2分钟）
```bash
cd frontend
npm install
```

## 第三步：启动开发服务器（1分钟）
```bash
npm run dev
```

## 第四步：验证效果（1分钟）
- 打开浏览器访问 http://localhost:8080
- 输入 "你好" 测试聊天
- 应该能看到流式打字机效果

## 发生了什么？
- Next.js 在 8080 端口启动开发服务器
- React 组件渲染聊天界面
- 通过 `/api/chat` SSE 接口调用后端
- 后端 Express 在 30000 端口响应

## 项目结构
```
frontend/src/
├── app/              # Next.js App Router 页面
├── components/       # React 组件
│   ├── ChatArea.tsx  # 聊天区域
│   ├── ChatInput.tsx # 输入框
│   └── admin/        # 管理后台组件
├── store/            # Zustand 状态管理
├── hooks/            # 自定义 Hooks
└── lib/              # 工具函数
```

## 常见问题

Q: 页面空白怎么办？
A: 检查浏览器控制台，确保后端 30000 端口已启动

Q: 样式丢失？
A: 确保执行了 `npm install`，依赖未安装会导致样式异常

Q: 为什么打字机效果卡顿？
A: SSE 流式响应依赖网络质量，确保后端 API 响应正常
