## 二、严重问题 (功能完全缺失)

### 2.1 MissionControl 后端API完全缺失

**问题描述**: `MissionControl` 组件使用纯前端 Zustand store，没有任何后端 API 连接。任务状态、Agent状态都是内存状态，页面刷新后数据丢失。

**缺失功能**:
| 功能 | 说明 |
|------|------|
| 任务持久化 | 任务队列状态未保存到后端 |
| Agent同步 | Agent池状态无后端管理 |
| 任务分配API | 任务分配逻辑纯前端 |
| SSE实时更新 | 无后端推送机制 |

**建议解决方案**:
1. 新增 `routes/missionControl.js` 路由
2. 复用已有的 `infra/queue/QueueManager.js`
3. 添加 SSE 端点推送任务状态变更

---

### 2.2 PerformanceMonitor 完全使用模拟数据

**问题描述**: `PerformanceMonitor` 组件所有数据都是**模拟的假数据** (使用 `setTimeout` 和 `Math.random()` 模拟)，没有调用任何后端 metrics API。

**缺失功能**:
| 功能 | 说明 |
|------|------|
| Prometheus metrics API | 无后端指标端点 |
| 实时指标收集 | 未对接 `infra/metrics/MetricsCollector.js` |
| 真实告警 | 纯前端模拟告警 |
| 真实优化建议 | 基于模拟数据的建议 |

**建议解决方案**:
1. 新增 `routes/metrics.js` 或 `routes/admin/stats.js`
2. 对接 `infra/metrics/MetricsCollector.js`
3. 暴露 Prometheus 格式指标

---

### 2.3 KnowledgeBase 单文档索引操作缺失

**缺失路由**:
| 功能 | 前端调用 | 后端路由 | 状态 |
|------|----------|----------|------|
| 单文档重建索引 | `POST /documents/{id}/reindex` | **不存在** | 缺失 |
| 清空索引 | `DELETE /index` | **不存在** | 缺失 |
| 索引配置保存 | ToggleSwitch UI | **不存在** | 缺失 |

## 四、低优先级问题

### 4.1 API_ENDPOINTS 配置未被使用

**问题**: `frontend/src/lib/apiConfig.ts` 中定义的端点缺少 `/api` 前缀，且未被实际使用。

```typescript
// apiConfig.ts (错误)
chat: `${API_BASE}/chat`  // -> http://localhost:30000/chat

// 实际后端
app.use('/api/chat', chatRoutes)  // -> http://localhost:30000/api/chat

// 实际使用
ChatArea 直接调用 sse.ts 的 sendSSEChatMessage -> `/api/v1/chat/completions`
```

---

### 4.2 ChatInput 快捷短语无后端同步

**问题**: 快捷短语数据完全来自前端 `customPrompts + DEFAULT_PROMPTS`，未从后端加载。

| 功能 | 现状 | 建议 |
|------|------|------|
| 快捷短语 | 仅本地数据 | 考虑添加后端 API 获取用户自定义短语 |
| 快捷设置 | 仅状态管理 | Temperature/MaxTokens 后端无法持久化 |

## 六、修复优先级建议

### P0 - 立即修复 (影响核心功能)

1. **MissionControl 后端API** - 核心任务队列功能完全不可用
2. **PerformanceMonitor 真实数据** - 监控数据完全虚假

### P1 - 高优先级 (影响管理后台)

1. **AdminDashboard stats API** - 管理后台统计页面无法加载
2. **ToolRegistry API修正** - 工具启用/禁用功能无法工作
3. **KnowledgeBase API路径统一** - 文档操作可能失败

### P2 - 中优先级 (体验优化)

1. **ChatInput 意图Banner** - 意图检测后无实际动作
2. **快捷短语后端同步** - 用户自定义短语无法持久化

### P3 - 低优先级 (配置清理)

1. **API_ENDPOINTS 配置清理** - 未使用的配置可能造成困惑
